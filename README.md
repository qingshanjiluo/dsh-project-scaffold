# dsh-project-scaffold

> DeepSeek Harness 项目脚手架插件

## 功能

- 📦 **模板系统**: 内置 React/Node/Python/Go/Rust/VSCode 模板
- 🚀 **快速创建**: 一键创建项目结构
- 📂 **模板预览**: 查看模板文件结构
- 🔧 **自定义**: 支持自定义模板目录

## 内置模板

- `react-app` — React 应用
- `node-api` — Node.js API 服务
- `python-cli` — Python CLI 工具
- `go-cli` — Go CLI 工具
- `rust-cli` — Rust CLI 工具
- `vscode-extension` — VS Code 扩展

## 工具

| 工具名 | 说明 |
|--------|------|
| `scaffold_list` | 列出模板 |
| `scaffold_preview` | 预览模板 |
| `scaffold_create` | 创建项目 |
| `scaffold_add_file` | 添加文件 |
